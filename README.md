# 渔场向导 · 海洋锋面分析系统（交互原型）

面向**渔场作业决策**的海洋锋面分析系统 · 纯前端交互原型。
所有数据为**示例数据**（确定性 mock，可复现），无第三方依赖、无构建步骤。

## 快速运行

浏览器直接打开 `prototype-fishing.html` 即可（改完建议 `Ctrl+F5` 强刷）。

## 信息架构（三层 · 主次分明）

```
L0 全局上下文（顶栏，唯一真源，按使用顺序编号）
   ① 从哪出发 · ② 找多远 10/20/30 km · ③ 找什么鱼 · ④ 出海日（◀ 日期 ▶）
        │
L1 结论层（hero 常驻，不随页签消失）
   「能不能出海」结论 + 首选点位（方位/距离/航时/油耗）+ 为什么这么判断
        │
L2 分层细节（页签）
   ┌ 主任务 ─────────────┬ 支撑 ───────────────┐
   │ 现在（观测数据）        │ 往年同期（历史规律）   │
   │ 未来（预报 7 天）       │ 依据（怎么算的）      │
   └─────────────────────┴────────────────────┘
```

- **唯一真源**：时间只有顶栏「出海日」一个控件（旧"观测/预报/气候"三档已删）；范围/鱼种/图层同样各只有一处
- **数据来源由页签决定**：「现在」页=观测、「未来」页=预报，不再需要单独选数据来源
- **单向数据流**：`state` → `render*()`；渲染函数只读 state，不写 state
- **依据页**：承载原「AI 分析」的可解释部分（数据从哪来 / 怎么算的 / 现在还做不到的）

## 原型能力

| 区域 | 能力 |
|---|---|
| 顶栏 | 经纬度定位、找鱼范围切换（10/20/30 km）、目标鱼种（带鱼/小黄鱼/鲐鱼/剑尖枪乌贼）、**出海日**（◀▶ 步进，越界自动钳制并提示）|
| 地图 | 海表温度纬向梯度 + 等温线、锋面线（F001–F003）、冷/暖侧带、值得去的水域、10/20/30 km 范围环、缩放/复位/定位脉冲、图层开关、点击要素高亮并压暗非目标 |
| **地图指针查询** | 鼠标移到任意点即显示：坐标 / 海表温度（+目标鱼种是否适温）/ 离你多远+方位 / 是否在范围内 / 最近锋面距离+方位+在哪一侧 / 是否在值得去的水域内；**点一下钉住**（十字标记），Esc 或点 ✕ 取消；落在陆地只说"这里是陆地" |
| 结论卡 | 三档结论（可以出海/谨慎出海/别出海）、首选+备选点位（方位/距离/航时/油耗）、「为什么这么判断」逐项加分 |
| 现在 | 眼下情况 4 格（水温/距最近锋面/所处侧别/把握）、天气与海况（能否出海）、找鱼范围内的锋面清单（可点选联动地图）|
| 未来 | 逐日把握 7 柱 + 7 行（**点某天即把「出海日」设成那天**）、最好的一天、1/3/7 天说明 |
| 往年同期 | 这一天 / 这个月 / 这一年的"有锋面的天数占比"（统一口径）、和往年比偏高/正常/偏低 + 对你的意义（**页内没有任何日期输入框**）|
| 依据 | 数据从哪来（7 行）、怎么算的（6 条）、现在还做不到的（4 条）|
| 交互回执 | 选中任何目标后地图上出现回执卡（名称/距离/方位/✕ 取消）；Toast 只用于操作确认 |
| 状态 | 空态（这天还没观测到 → 给"去看未来"直达按钮）、范围回退（范围内无命中→先给最近的并标注）|

## 交互逻辑要点

1. **单一选中语义 + 必有回执**：地图要素与卡片条目共用 `state.select`，点击后地图上出现回执卡，`✕`/Esc 都能取消
2. **几何同源**：距离/方位由经纬度实时计算；地图投影保证东西/南北向 1 km 等长，半径圈是正圆；渔场区半轴用公里定义
3. **时间语义**：只剩「出海日」一个真源；观测覆盖 2024-06-01~09-30，预报到今天+6 天，选到未来时"现在"页明确说没观测、结论卡自动改用预报
4. **安全优先**：不能出海一律「别出海」，把握不再凌驾于安全之上
5. **可访问性**：页签 `role=tab`、支持 ←/→ 方向键切换；Esc 取消钉住/选中

## 技术说明

- 纯原生 HTML + JS（ES2017+，无依赖、无构建）
- 演示投影：`500 + (lon − 124.5) × 180`、`320 − (lat − 30.2) × 208`；比例 `1.877 px/km`（东西/南北等长，半径圈才是正圆）
- 颜色带与数值同源：SST 由纬度线性插值（22–33 °C，北冷南暖），等温线、卡片温度、指针浮层三者一致
- 地图指针查询用 `svg.getScreenCTM()` 反算经纬度（缩放/裁切后依然准确），`mousemove` 走 `requestAnimationFrame` 节流
- 所有 mock 使用 FNV-1a 哈希 + 确定性函数，**同一输入永远同一输出**，便于回归比对
- 航时/油耗口径：8 kn 巡航（14.8 km/h）、1.6 L/km（仅量级参考）

## 自检方式

```bash
node --check prototype-fishing.js        # 语法检查
node tools/e2e-check.mjs                 # 交互端到端（54 项断言，含截图输出到 %TEMP%）
node tools/layout-check.mjs              # 布局几何（20 项，1680/1280 两档）
```

- 两个脚本通过 Edge 无头 + CDP 驱动，仅依赖 Node 18+（使用内置 `fetch` / `WebSocket`）；可用环境变量 `EDGE`、`PAGE` 覆盖浏览器路径与页面地址
- 覆盖：顶栏 4 组编号与时间入口唯一性、页签层级、结论层文案、四个页签内容、指针查询（含陆地/钉住/Esc/边界）、选中回执、图层重绘、鱼种与范围联动、空态与日期钳制、方向键可访问性、运行期异常、两档宽度的溢出与裁切
