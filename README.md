# 渔场向导 · 海洋锋面分析系统（交互原型）

面向**渔场作业决策**的海洋锋面分析系统 · 纯前端交互原型。
所有数据为**演示占位**（确定性 mock，可复现），无第三方依赖、无构建步骤。

## 快速运行

浏览器直接打开 `prototype-fishing.html` 即可（改完建议 `Ctrl+F5` 强刷）。

## 信息架构（三层 · 主次分明）

```
L0 全局上下文（顶栏，唯一真源）
   定位 · 作业半径 10/20/30 km · 目标鱼种 · 时间条（日期 ◀▶ + 观测/预报/气候）
        │
L1 结论层（hero 常驻，不随页签消失）
   「可否出海」结论 + 首选点位（方位/距离/航时/油耗）+ 依据折叠
        │
L2 分层细节（页签）
   ┌ 主任务 ─────────────┬ 支撑 ──────────────┐
   │ 现在（现场判读）        │ 规律（历史同期口径）  │
   │ 未来（1/3/7 天窗口）    │ 依据（口径与局限）    │
   └─────────────────────┴───────────────────┘
```

- **唯一真源**：时间与范围控件只存在于顶栏；卡片内不再出现第二套时间控件
- **单向数据流**：`state` → `render*()`；渲染函数只读 state，不写 state
- **依据页**：承载原「AI 分析」的可解释部分（数据来源、判定规则、局限），不再是重复给结论的页签

## 原型能力

| 区域 | 能力 |
|---|---|
| 顶栏 | 经纬度定位、作业半径切换、目标鱼种（带鱼/小黄鱼/鲐鱼/剑尖枪乌贼）、时间条（◀▶ 步进、观测/预报/气候三族）|
| 地图 | SST 纬向梯度 + 等温线、锋面线（F001–F003）、冷/暖侧带、渔场高概率区、10/20/30 km 半径环、缩放/复位/定位脉冲、图层开关、**点击要素高亮并压暗非目标** |
| 结论卡 | 三档结论（可出海/谨慎出海/暂缓出海）、首选+备选点位（方位/距离/航时/油耗）、依据逐项加分说明 |
| 现在 | 关键指标 4 格（海温/距最近锋面/所处侧别/可能度）、海况与适航、范围内锋面清单（可点选联动地图）|
| 未来 | 1/3/7 天可能度、逐日 7 天窗口柱图与最佳窗口、逐日海况 |
| 规律 | 按日/按月/按年出现率（**统一口径**：有锋面天数/有效天数）、多年同期与异常提示（直接给作业含义）|
| 依据 | 数据来源与时次表、6 条判定规则与口径、4 条局限与待接入 |
| 状态 | 无数据态（超覆盖时次）、范围回退（半径内无命中→回退最近并标注）、Toast 仅用于操作确认 |

## 交互逻辑要点

1. **单一选中语义**：地图要素与卡片条目共用 `state.select`，任何位置点击同一条目效果一致
2. **几何同源**：定位点到锋面的距离/方位由经纬度折线实时计算，地图与卡片数值天然一致
3. **时间族语义**：观测（数据覆盖期外→空态）、预报（滚动 7 天窗口，越界自动收敛到今天）、气候（多年同期）
4. **安全优先**：不适航一律「暂缓出海」，可能度不再凌驾于安全之上
5. **可访问性**：页签 `role=tab`、支持 ←/→ 方向键切换

## 技术说明

- 纯原生 HTML + JS（ES2017+，无依赖、无构建）
- 演示投影：`500 + (lon − 124.5) × 180`、`320 − (lat − 30.2) × 220`；距离环 `1.87 px/km`
- 颜色带与数值同源：SST 由纬度线性插值（22–33 °C，北冷南暖），等温线与卡片温度一致
- 所有 mock 使用 FNV-1a 哈希 + 确定性函数，**同一输入永远同一输出**，便于回归比对
- 航时/油耗口径：8 kn 巡航（14.8 km/h）、1.6 L/km（仅量级参考）

## 自检方式

```bash
node --check prototype-fishing.js        # 语法检查
node tools/e2e-check.mjs                 # 交互端到端（30 项断言，含截图输出到 %TEMP%）
node tools/layout-check.mjs              # 布局几何（1680/1280 两档，无溢出/无裁切/无重叠）
```

- 两个脚本通过 Edge 无头 + CDP 驱动，仅依赖 Node 18+（使用内置 `fetch` / `WebSocket`）；可用环境变量 `EDGE`、`PAGE` 覆盖浏览器路径与页面地址
- 覆盖：页签层级、时间真源唯一性、选择态联动、空态与回退、图层重绘、鱼种切换、方向键可访问性、运行期异常
