# 渔场向导 · 海洋锋面分析系统（交互原型）

面向**渔场作业决策**的海洋锋面分析系统 · 纯前端交互原型。
数据：**真实锋面数据**（Zenodo 20356239 · CC BY 4.0，0.05° 逐日）+ **真实海温**（NOAA GHRSST 0.05° 逐日，与锋面不同源）+ **公有领域底图**（Natural Earth 1:10m），由脚本预生成到 `data/`，双击即可离线打开。
锋面强度 / 海况 / 预报 / 渔场**没有真实数据**，页面对这些一律标「待接入」或「示例」，**不插值、不哈希、不编数**（需求 FR-7）。

## 快速运行

浏览器直接打开 `prototype-fishing.html` 即可（改完建议 `Ctrl+F5` 强刷）。
重新生成数据见 [`docs/data-schema.md`](docs/data-schema.md) 与 [`data/README.md`](data/README.md)。

## 信息架构（三层 · 主次分明）

```
L0 全局上下文（顶栏，唯一真源，按使用顺序编号）
   ① 从哪出发 · ② 找多远 10/20/30 km · ③ 出海日（◀ 日期 ▶）
        │
L1 结论层（hero 常驻，不随页签消失）
   「这天值不值得去」结论 + 首选锋面对象（方位/距离/航时/油耗）+ 为什么这么判断
        │
L2 分层细节（页签）
   ┌ 主任务 ─────────────┬ 支撑 ───────────────┐
   │ 现在（真实观测）        │ 往年同期（多年度真实统计）│
   │ 未来（预报未接入，说清楚）│ 依据（怎么算的）        │
   └─────────────────────┴────────────────────┘
```

- **唯一真源**：时间只有顶栏「出海日」一个控件；范围/图层同样各只有一处（目标鱼种本期不做，见 `docs/ux-spec.md` §3.2）
- **数据来源由页签决定**：「现在」页=观测；「未来」页没有预报数据就明说，不给编造的未来数字
- **单向数据流**：`state` → `render*()`；渲染函数只读 state，不写 state
- **依据页**：数据来源（含 DOI 与许可）、判定规则、现在还做不到的

## 原型能力

| 区域 | 能力 |
|---|---|
| 顶栏 | 经纬度定位、作业范围切换（10/20/30 km）、**出海日**（◀▶ 步进，越界自动钳制并提示）|
| 地图 | **真实底图**：陆地是**浅色实色块**（`#3a5068`，与海面 `#0d2135` 明显区分）+ 亮色海岸线（Natural Earth 1:10m，含 200 m·1000 m 等深线）；默认视野缩放 0.8，保证东海海岸线在画面内（可滚轮缩放/拖拽平移/◎ 复位）。叠加 **真实海温场**（NOAA GHRSST，0.5 °C 分档色带）+ **真实锋面**：锋面带（数据原样）、锋面对象中心线与编号（F001…，标注真实长度 km）、冷侧/暖侧（数据里的 −20/20 编码）、海上没有观测的像元（−128，斜线纹理，只出现在海上）、真实整数度经纬网、比例尺、10/20/30 km 范围环、6 个图层开关、点击要素高亮并压暗非目标 |
| **地图指针查询** | 鼠标移到任意点即显示：坐标 / 数据类型（**锋面线含原始编码 −10/10/30 / 冷侧 / 暖侧 / 无观测**）/ **该格真实水温（NOAA GHRSST，按 0.5 °C 档位）** / 离你多远+方位 / 是否在作业范围内 / 最近锋面（真实锋面区编号+长度）；**点一下钉住**（十字标记），Esc 或点 ✕ 取消 |
| 结论卡 | 三档结论（值得去/可以看看/线索不足）、首选+备选锋面区（方位/距离/航时/油耗）、「评分依据」逐项加分（含数据覆盖）|
| 现在 | 当前渔情 4 格（锋面区数/最近锋面/所处侧/把握度）、范围标签含数据覆盖与**定位点水温**、海况与安全（**标示例数据 · 仅供参考**）、范围内的锋面区清单（可点选联动地图）|
| 未来 | 没有预报数据 → 说明原因与补数据前提；列出可选日期（最多 14 条 + 汇总行，**点一下即切换「出海日」**）|
| 历史同期 | 当日 / 近三日 / 当月：真实多年度对比（`front_present` 唯一口径），缺样本的年份显示「缺测」；整月样本不足就直说（**页内没有任何日期输入框**）|
| 数据说明 | 数据来源（12 行，含 DOI/许可/底图出处）、评分规则（6 条）、使用限制（逐条列出未接入项与合规要求）|
| 交互回执 | 选中任何目标后地图上出现回执卡（名称/长度/距离/侧别/✕ 取消）；Toast 只用于操作确认 |
| 状态 | 空态（没导出的日期 → 说明可选范围）、范围回退（范围内无对象→先给最近的并标注）|

## 交互逻辑要点

1. **单一选中语义 + 必有回执**：地图要素与卡片条目共用 `state.select`，点击后地图上出现回执卡，`✕`/Esc 都能取消
2. **几何同源**：距离/方位由经纬度实时计算；地图投影保证东西/南北向 1 km 等长，半径圈是正圆；锋面中心线、卡片距离、指针查询用的是同一份数据
3. **时间语义**：只剩「出海日」一个真源；可选范围＝`data/day/` 里实际导出的日期，口径统一写"观测"
4. **不编造**：锋面与海温都是真实数据（海温标明与锋面数据不同源）；强度 / 海况 / 预报 / 渔场一律标注；页面不出现插值出来的温度，也不出现按月衰减出来的"未来把握"
5. **可访问性**：页签 `role=tab`、支持 ←/→ 方向键切换；Esc 取消钉住/选中

## 技术说明

- 纯原生 HTML + JS（ES2017+，无依赖、无构建）；数据以 `<script>` 引入，`file://` 双击可跑
- 演示投影：`500 + (lon − 124.5) × 180`、`320 − (lat − 30.2) × 208`；比例 `1.877 px/km`（东西/南北等长，半径圈才是正圆）
- 图层渲染：栅格类（海温 / 冷暖侧 / 锋面带 / 缺测）用**逐行 RLE 还原成矩形并合成单个 `<path>`**——相邻行同起止的游程会合并，一个 DOM 节点承载上千格且不露缝；线要素（对象中心线）画折线，**只在显示层做 Catmull-Rom 平滑**，距离/命中判定仍用原始点
- 海温图层：按数据里的 **0.5 °C 档位**取色（一档一个 `<path>`，档位数 = 数据文件里的档位数），指针查询给该格真实档位值
- 地图：真实整数度经纬网（含度数标注）、比例尺（图上 50 km 实时换算）、滚轮以光标为中心缩放、拖拽平移、`◎` 回到定位点
- 地图指针查询用 `svg.getScreenCTM()` 反算经纬度（缩放后依然准确），`mousemove` 走 `requestAnimationFrame` 节流
- 「数据把握」全部由真实锋面数据算出：范围内对象数、最近锋面距离、范围内最长对象、观测覆盖；海温虽已接入但**不参与评分**（没有真实渔获/适温数据时不拿温度下结论）
- 唯一保留的示例值是海况（风/浪/涌），用确定性哈希生成，页面标注「示例数据 · 不参与结论」
- 航时/油耗口径：8 kn 巡航（14.8 km/h）、1.6 L/km（仅量级参考）

## 自检方式

```bash
node --check prototype-fishing.js        # 语法检查
node --check prototype-data.js
node tools/data-check.mjs                # 数据文件结构与自洽（每个数据天 14 项 + 海温 / 清单断言）
node tools/e2e-check.mjs                 # 交互端到端（含覆盖层可见性、海温与数据一致、截图到 %TEMP%）
node tools/layout-check.mjs              # 布局几何（1680/1280 两档）
```

- 三个浏览器脚本通过 Edge 无头 + CDP 驱动，仅依赖 Node 18+（使用内置 `fetch` / `WebSocket`）；可用环境变量 `EDGE`、`PAGE` 覆盖浏览器路径与页面地址
- 覆盖：真实数据接入（DOI/许可/日期范围/图层数量与数据一致）、顶栏 3 组编号与时间入口唯一性、页签层级、三档结论与逐项加分、四个页签内容、指针查询（真实编码/缺测/钉住/Esc/边界）、选中回执、图层重绘、范围联动、日期钳制与空态、**覆盖层可见性（computed style + 命中测试）**、方向键可访问性、运行期异常、两档宽度的溢出与裁切
- **不编造断言**：页面里不允许出现插值温度或衰减出来的未来把握（e2e 直接检查页面文本）
