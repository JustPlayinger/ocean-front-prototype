# 渔场向导 · 海洋锋面分析系统（交互原型）

面向**渔场作业决策**的海洋锋面分析系统 · 纯前端交互原型。
所有数据为**演示占位**，无真实海洋数据，无构建依赖。

## 快速运行

用浏览器直接打开根目录的 `prototype-fishing.html` 即可（修改后建议 `Ctrl+F5` 强刷缓存）。

## 目录结构

```
ocean-front-prototype/
├── prototype-fishing.html        # 原型页面（布局 + 样式 + 结构）
├── prototype-fishing.js          # 原型交互逻辑（SVG 地图 / 面板 / 联动）
└── docs/
    └── requirements-fishing-ground.md   # 需求规格 v0.2
```

## 原型能力

- 顶栏：定位查询（经纬度）、时间尺度（单日 / 连续多日 / 整月 / 整年）、日期联动
- 地图：SST 温度场 + 等温线、冷/暖侧带、锋面线、渔场高概率区、10/20/30 km 距离环、缩放/复位/定位脉冲
- 图层开关：海表温度 / 锋面线 / 冷侧 / 暖侧 / 渔场区 可独立显隐，真实重绘
- 右侧面板（四页签）：
  - **当前**：当前环境指标；活动范围信息条目**可点击 → 地图对应要素高亮**
  - **历史**：按日 / 按月 / 按年任选时间点查看出现率柱图与多年同期对比
  - **预测**：范围锋面判定（范围内命中 / 范围外最近回退）与未来 3 日可能度
  - **AI 分析**：结论摘要与下一步建议

## 技术说明

- 纯原生 HTML + JS（ES2017+），无第三方依赖、无构建步骤
- 坐标演示逻辑：`500 + (lon − 124.5) × 180`，`320 − (lat − 30.2) × 220`（px）；距离环按 1.87 px/km 换算
- 数据为“代码内置 mock”，对接真实后端/数据时按 `docs/requirements-fishing-ground.md` 演进
