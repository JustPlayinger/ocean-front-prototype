# Decide Product UI Scope For AIS Response Evidence

Labels: `wayfinder:prototype`

## Question

What should the P1 product UI show once the AIS response table contains real values?

The decision must settle:

- What the current-page "历史 AIS 响应" card shows in collapsed form.
- What the expanded response-detail section shows.
- Whether the history page should include a "相似锋面事件响应" module in P1 or wait for P2.
- Whether the fishing-effort map layer appears in P1.
- How to keep users from reading the evidence as catch or production prediction.

Recommended default:

For P1, current page shows qualitative response state plus a compact evidence sentence; expanded details show fishing hours, lift, control value, and caveat. Put the similar-event module behind a small history-page section only after at least a few real comparable events exist. Keep the map layer optional.
