# 需求规格：面向渔场预测的海洋锋面分析系统

> 版本：v0.2（重定位版）
> 日期：2026-09-08
> 依据：`9.3.md` 定位更新、原课题文档（1-12 周）、数据实测结论
> 仓库：本仓（原型与需求独立托管；接入真实数据/后端时再补充对接说明）

---

## 1. 项目定位

**面向渔场作业的海洋锋面分析系统**：以海洋锋面为核心环境因子，向渔民/渔业管理者提供"渔场在哪里、何时去、风险如何"的决策支持。

系统回答三类问题：
1. 当前位置/目标海域，**现在**有没有值得关注的锋面与渔场线索？
2. 这一带**过去**（近 1 月/1 年/历史同期）锋面活动规律如何？
3. **未来**（短临/数日）锋面会如何演化、渔场可能性如何变化？

> 定位转变对照：v0.1 定位是"海洋锋面时空任务分析工具"（面向科研演示）；v0.2 定位转向"渔场作业辅助"，一切功能围绕"渔场决策"收敛。

## 2. 范围与排除

### 2.1 本期范围（1-2 个月里程碑）
- 重做信息架构：三维时间视角 + 四功能区（当前/历史/预测/AI 分析）
- 定位半径内锋面 + 渔场综合展示；自由缩放与按需加载
- 时间尺度扩展：单日 → 连续多日 → 整月 → 整年
- 查询性能优化（经纬度定位加载提速）
- 界面精简与配色优化；移除与决策无关的工程数据
- 预测算法定义与原型（历史 + 冷暖结构 + 锋面强度 等多因素）

### 2.2 明确排除（后续版本）
- 三维地球视图（延后）
- AIS/渔场数据接入与分析视图（数据到位后单独视图）
- 真实本地大模型推理（可暂以规则 AI 兜底）
- 手机端、离线安装包

### 3.1 右侧功能分区（与 9.3.md 一致）
仅保留以下四类功能卡片，其余模块与过程性数据展示一律移除：

| 分区 | 回答的问题 | 主要内容 |
|---|---|---|
| ① 当前情况 | 现在这里有什么？ | 定位点当前 SST、锋面距离/侧别、附近锋面对象、渔场线索（后续） |

## 4. 功能需求

### 4.1 时空交互（前端）

| 编号 | 需求 | 验收标准 |
|---|---|---|
| FR-1 | 地图以定位点为圆心，默认加载半径内全部图层；半径外按需加载 | 首次定位 ≤ 2s 显示核心图层；拖动/缩放再取周边瓦片 |
| FR-2 | 支持缩放/平移，缩放无死区，不整页刷新 | 操作流畅（交互帧率可用），无数据区给"加载中/无数据"提示 |
| FR-3 | 位置输入与地图点选两种定位方式 | 输入经纬度或点选均可定位，两种方式结果一致 |
| FR-4 | 时间尺度三档：单日 / 整月 / 整年（及连续多日），可跨档切换 | 切换尺度后统计与图层自动更新，尺度标识清晰 |
| FR-5 | 时空维度信息完整：选定经纬度后，展示该活动范围内的当前、月、年视图 | 三个尺度切换入口均可达，且数据口径一致（见 §5.2） |
| FR-6 | 渔场信息预留叠加层（数据到位后启用） | 图层开关存在；数据就绪后可显示点位/范围 |
| FR-7 | 低信息密度提示：无数据/超出范围给出明确提示，不展示编造值 | 无数据与有数据的展示可区分 |

### 4.2 视图组织（三个时间视角，9.3.md 原话"过去/当前/预测"）

| 视角 | 内容 | 默认进入 |
|---|---|---|
| 当前视图 | 当日 SST + 锋面 + 冷暖侧 + 定位点 + 距离标注 | 首页默认 |
| 历史视图 | 月/年尺度的频率、出现日期分布、多年对比 | 顶栏切"月/年"时进入 |
| 预测视图 | 未来数日锋面可能性（原型口径） | 切"预测"分区进入 |

### 4.3 渔场专项（延后，见 §8）
AIS 渔业数据到位后，新增"渔场视图"：作业船位热力 → 实际渔场高频区 → 与锋面距离分布 → 渔场时空规律。不进入本期验收。

## 5. 后端与数据

### 5.1 数据源与口径（以已确认事实为准）
| 数据 | 用途 | 现状 |
|---|---|---|
| `front` 锋面位置（Zenodo 0.05°） | 锋面线/冷暖侧/对象 | 已有样例 |
| `frontal_intensity` 锋面强度 | 强度分级、预测特征 | 未接入（需下载） |
| `analysed_sst`（C3S 0.05°） | SST 底图、温度统计 | 需真实数据 |
| GEBCO 水深/海岸线 | 底图本地化、海陆掩码 | 未接入 |
| AIS 渔业分析数据 | 渔场图层（未来） | 待提供 |

### 5.2 历史概率统一口径（依据 9.3.md）
- 只保留一个口径：**该点/该范围在所选时间窗内出现锋面的占比**。
  `频率 = 窗口内有锋面的有效日期数 / 窗口内有效日期总数`
- 时间窗支持：连续 N 日、指定月份、指定年份、历史同期（多年同月同日）。
- 移除多重概率定义、覆盖可信度等复杂标签；注释中保留计算公式供查证。

### 5.3 后端需求

| 编号 | 需求 | 说明 |
|---|---|---|
| BR-1 | 区域预裁剪 + 本地缓存 | 首次按 bbox 读取后缓存为本地切片/瓦片，避免重复读全球网格 |
| BR-2 | 分层按需渲染：重要信息优先 | 首帧=海岸线+底图，其次 SST，再叠加锋面/对象，最后统计面板 |
| BR-3 | 地形/海岸线本地存储 | 不依赖在线底图服务，全部本地数据 |
| BR-4 | 加载性能：定位点经纬度查询提速 | 目标：1° 窗口核心信息首屏 ≤ 2s；需先定位瓶颈（IO/解码/渲染） |
| BR-5 | 时间聚合接口 | 单日/月/年三类聚合服务，避免前端逐日拉取 |
| BR-6 | 三维预留 | 渲染与数据接口保持与地图实现解耦，便于未来替换球面视图 |

### 5.4 前端工程需求
- 保持 React + MapLibre（当前栈），不引入重型地图库；
- 组件按"当前/历史/预测/AI"分区拆分，降低单文件体积（现状 App.tsx 过大，影响维护）。

## 6. 预测（本期为"算法定义 + 原型验证"，暂缓产品化）

### 6.1 预测目标
未来 L 天（L=1/3/7）某格点/区域**出现锋面（进而作为渔场线索）的可能性**。

### 6.2 预测输入（多因素，与 9.3.md 一致）
| 因素 | 说明 |
|---|---|
| 过去情况 | 历史同期锋面出现频率（§5.2 口径） |
| 冷暖情况 | 近期冷暖侧结构变化、SST 距平 |
| 锋面强度 | `frontal_intensity` 与局地温度梯度 |
| （后续）流场/风场 | GLORYS12 / ERA5，数据到位后加入 |

### 6.3 方法建议
- 先建立基线：持续性（今天有锋面→明天概率）+ 气候态（历史频率）。
- 在基线上迭代规则/统计/机器学习模型，要求可解释、可回看。
- 创新点定位（9.3.md）：设计**综合过去、冷暖、强度等多因素的复合概率算法**，与单一因素基线对比给出提升。

### 6.4 验收标准
- 预测接口返回可解释的"未来 L 天概率场 + 依据说明"；
- 有离线回测（用历史日期切分验证），指标可复现。

## 7. 性能与体验（9.3.md："查找经度纬度时加载过慢"）

| 目标 | 场景 | 指标 |
|---|---|---|
| 定位首屏 | 输入经纬度后 | ≤2s 出当前视图核心图层 |
| 尺度切换 | 单日 → 整月/整年 | ≤3s 出聚合结果（命中缓存时 ≤1s） |
| 地图漫游 | 缩放/平移 | 无整页加载感，无数据时有占位 |
| 首包体积 | 生产构建 | 无明显大 chunk 警告（现状 1.2MB 需代码分割） |

优化方向（按收益排序）：切片/瓦片缓存 → 聚合接口 → 按需加载 → 前端分包。
