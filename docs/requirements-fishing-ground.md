## 1. 项目定位

**面向渔场作业的海洋锋面分析系统**：以海洋锋面为核心环境因子，向渔民/渔业管理者提供"渔场在哪里、何时去、风险如何"的决策支持。

系统回答三类问题：
1. 当前位置/目标海域，**现在**有没有值得关注的锋面与渔场线索？
2. 这一带**过去**（近 1 月/1 年/历史同期）锋面活动规律如何？
3. **未来**（短临/数日）锋面会如何演化、渔场可能性如何变化？

> 定位转变对照：v0.1 定位是"海洋锋面时空任务分析工具"（面向科研演示）；v0.2 定位转向"渔场作业辅助"，一切功能围绕"渔场决策"收敛。

## 3. 界面信息架构（首页/主工作台）

> v0.3 起改为**三层结构**：L0 全局上下文（唯一真源）→ L1 结论层（常驻）→ L2 分层细节（页签）。
> 详细规范与调研依据见 `docs/ux-spec.md`。

```
┌──────────────────────────────────────────────────────────────────────┐
│ L0 顶栏：① 从哪出发 · ② 找多远(10/20/30km) · ③ 出海日(◀ 日期 ▶)          │
├──────────────────────────────────┬───────────────────────────────────┤
│                                  │ L1 结论层（常驻 hero）：            │
│                                  │   可否出海 + 首选点位 + 为什么       │
│     主地图（二维，可缩放）           ├───────────────────────────────────┤
│   SST/等温线/锋面/冷暖侧/渔场区       │ L2 页签：                          │
│   /作业半径环/定位点/指针查询浮层      │   当前 · 历史 · 预测 · AI 分析       │
└──────────────────────────────────┴───────────────────────────────────┘
```

**四条硬约束**
1. **时间、范围、出发地只有一处真源**（L0 顶栏）；卡片内不得再出现第二套时间/范围控件。时间维度只有"出海日"一个控件，观测 / 历史 / 规则预测参考 / AI 证据组织由页签决定。
2. **结论先于细节**：L1 常驻，任何页签切换都不隐藏结论；结论必须可执行（方位+距离+航时）。
3. **无数据不编造**：缺数据时给明确原因与可行动作，不给结论（FR-7）。
4. **控件唯一性**：任一可调维度（时间/范围/图层）全站只出现一处（FR-16）。

### 3.1 右侧功能分区（四类功能保留，职责重新划分）

| 分区 | 层级 | 回答的问题 | 主要内容 | 明确不做 |
|---|---|---|---|---|
| ① 当前 | 主任务 | 这里当前是什么情况？ | 眼下情况（水温 / 距最近锋面 / 所处侧别 / 去这里的把握）、作业线索；天气海况与全部锋面清单放入展开项 | 不放多年统计，不默认铺满长清单 |
| ② 历史 | 支撑 | 过去这片海有什么规律？ | 当日 / 3 日 / 7 日 / 15 日 / 当月 / 整年六档；同期 `front_present` 与已导出实况样例并列，样本不足直接说明 | **页内不得有日期控件**（锚点用顶栏"出海日"） |
| ③ 预测 | 主任务 | 未来 7 天里哪天更值得关注？ | 规则预测参考（当前锋面信号 + 近几日持续性 + 历史同期）、最好的一天、7 天柱图；逐日明细可展开 | 不冒充真实业务预报 |
| ④ AI 分析 | 支撑 | 如何把当前/历史/预测证据组织成建议？ | 一张复核卡：本地证据摘要、下一步建议；任务编排和证据链可展开 | 不生成新的科学数值，不重复复杂概率口径 |

> 说明：v0.7 按 9.3 沟通记录恢复「AI 分析」独立入口，但职责限定为证据组织与任务编排；结论仍保留在 L1，数据来源与限制仍集中在页脚「数据说明」。

## 4. 功能需求

### 4.1 时空交互（前端）

| 编号 | 需求 | 验收标准 |
|---|---|---|
| FR-1 | 地图以定位点为圆心，默认加载半径内全部图层；半径外按需加载 | 首次定位 ≤ 2s 显示核心图层；拖动/缩放再取周边瓦片 |
| FR-2 | 支持缩放/平移，缩放无死区，不整页刷新 | 操作流畅（交互帧率可用），无数据区给"加载中/无数据"提示 |

| FR-4 | 时间由 L0 顶栏**唯一**真源"出海日"表达（日期 + ◀▶ 步进 + 播放 / 暂停 + 时间轴；范围＝`frontend/prototype/data/day/` 已导出的观测日期，本次 2024-07-01 ~ 08-31，越界自动钳制并说明原因）；旧"观测/预报/气候"三档一律取消 | 任一日期变化后地图与全部卡片同步；全站只有 1 个日期输入框，播放与时间轴同步同一个 `state.date`，页内没有任何日期输入框 |
| FR-5 | 时空信息完整：同一页内可看"当前（观测）/ 历史（过去）/ 预测（规则预测参考）/ AI 分析"，四者说法一致（见 §5.3 唯一口径） | 四个页签直达；"当前"页只讲观测，"预测"页标注规则预测参考，不需要另找地方切换数据来源 |
| FR-6 | 渔场信息预留叠加层（数据到位后启用） | 图层开关存在；数据就绪后可显示点位/范围 |
| FR-7 | 低信息密度提示：无数据/超出范围给出明确提示，不展示编造值 | 无数据与有数据的展示可区分 |

### 4.2 视图组织（三层 / 四页签，对齐 9.3.md 原话"过去/当前/预测"）

| 层/页签 | 内容 | 进入方式 |
|---|---|---|

| ② 历史 | 当日 / 3 日 / 7 日 / 15 日 / 当月 / 整年：真实多年度 `front_present` 占比、已导出实况样例聚合、连续日期格子图、样本缺口提示 | 页签「历史」（页内无日期控件） |

### 4.3 渔场专项（延后，见 §8）
AIS 渔业数据到位后，新增"渔场视图"：作业船位热力 → 实际渔场高频区 → 与锋面距离分布 → 渔场时空规律。不进入本期验收。

v0.11 的渔业响应路线不直接使用“渔获量”或“产量”作为真值，而使用 GFW 风格的 apparent fishing effort，即由 AIS 行为估计得到的表观捕捞小时数。产品界面将其表达为“历史 AIS 响应”“表观捕捞活动响应”或“作业线索”，并在数据说明中解释其不是真实渔获量。

> 许可提醒：Global Fishing Watch 公开数据为 **CC BY-NC 4.0（仅非商业）**，商用需另行授权；在拿到许可或合作方数据之前，地图上的"值得去的水域"只能作为**示例占位**并显式标注。

## 5. 后端与数据

### 5.1 数据源与口径（以已确认事实为准）

### 5.2 AIS 作业响应分析口径（v0.11 规划）

- **空间匹配**：围绕锋面事件计算 10 / 20 / 30 km 缓冲区内的 apparent fishing effort，界面默认 20 km，研究报告展示三半径敏感性。
- **时间窗口**：展示锋面事件前 7 天至后 7 天，默认解释后 1-3 天响应。
- **响应增强**：后 1-3 天 fishing hours 至少比前 7 天均值高 20%，且高于同日非锋面对照区域。
- **对照区域**：同日、同海区、离锋面至少 50 km 的同面积非锋面区域。
- **相似事件**：同一海区、前后 15 天季节窗口内的历史锋面事件；形态、长度、方向、强度作为后续增强特征。
- **产品评分**：GFW 数据接入后，“渔场可能性”由当前锋面线索和历史 AIS 响应共同构成，第一版权重为 50% / 50%，实现和回测后再决定是否固化。
- **公开边界**：GFW 衍生数据先用于本地/课堂演示和聚合图展示，不公开发布底层数据文件。
- **缺测边界**：AIS/GFW missing coverage 表示数据不可用或覆盖不足，不能当作 zero fishing activity。

> 数据落盘与生成流程、字段级结构、已知坑：见 `docs/data-schema.md`。

### 5.3 历史概率统一口径（依据 9.3.md）
- 只保留一个口径：**该点/该范围在所选时间窗内出现锋面的占比**。
  `频率 = 窗口内有锋面的有效日期数 / 窗口内有效日期总数`
- 时间窗支持：连续 N 日、指定月份、指定年份、历史同期（多年同月同日）。
- 移除多重概率定义、覆盖可信度等复杂标签；注释中保留计算公式供查证。
- v0.10 落地情况：已实现「当日 / 3 日 / 7 日 / 15 日 / 当月 / 整年」六个入口；当日与 3 日使用多年同期统计，7 日 / 15 日 / 当月 / 整年使用 2024-07-01 ~ 08-31 已导出实况样例聚合，并通过日期格子图展示连续尺度，同时明确提示多年连续窗口 / 整月 / 全年样本缺口。
- v0.6 现状：单日地图图层扩到 2024-07-01 ~ 08-31 共 62 天；同期样本仍为 2015—2024 的 8 月 5—7 日
  （个别年缺 1 天，按「有效天数」算并写明抽样口径）。

## 6. 预测（本期为"算法定义 + 原型验证"，暂缓产品化）

### 6.1 预测目标
未来 L 天（L=1/3/7）某格点/区域**出现锋面（进而作为渔场线索）的可能性**。

### 6.2 预测输入（多因素，与 9.3.md 一致）
| 因素 | 说明 |
|---|---|
| 过去情况 | 历史同期锋面出现频率（§5.3 口径） |
| 冷暖情况 | 近期冷暖侧结构变化、SST 距平 |
| 锋面强度 | `frontal_intensity` 与局地温度梯度 |
| （后续）流场/风场 | GLORYS12 / ERA5，数据到位后加入 |

### 6.3 方法建议
- 先建立基线：持续性（今天有锋面→明天概率）+ 气候态（历史频率）。
- 在基线上迭代规则/统计/机器学习模型，要求可解释、可回看。
- 创新点定位（9.3.md）：设计**综合过去、冷暖、强度等多因素的复合概率算法**，与单一因素基线对比给出提升。

### 6.4 验收标准
- 预测接口返回可解释的"未来 L 天概率场 + 依据说明"；
- 有离线回测（用历史日期切分验证），指标可复现。
