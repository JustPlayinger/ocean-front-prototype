# 交接文档 · 海洋锋面渔情原型（渔场向导）

## 1. 这是什么

东海一带（120–128°E / 27–34°N）的**渔场线索原型**：给定「出发地 / 作业范围 / 出海日」，回答三件事——这一带有没有锋面、值不值得跑一趟、先去哪一条。

技术形态：**纯前端静态页面**。1 个 HTML（结构与样式）+ 2 个 JS（状态机与渲染、数据适配层）+ 一组脚本生成的 JSON-in-JS 数据文件。无构建、无框架、无外部依赖、不联网，双击 HTML 即可运行。

## 2. 先跑起来 / 怎么算"改对了"

```powershell
# ① 打开页面（无需服务器）
start prototype-fishing.html

# ② 三项检查（Node 18+；e2e 需要本机装有 Edge）
node tools/data-check.mjs     # 数据文件结构与自洽：890 项断言
node tools/e2e-check.mjs      # 交互端到端（无头 Edge + CDP）：81 项断言
node tools/layout-check.mjs   # 布局几何（1280 / 1680 两档）：23 项断言
```

三项都必须 **0 失败**才算改对；`e2e-check` 每次会覆盖写截图到 `%TEMP%\shot-1-now.png` … `shot-10-empty.png`（Windows 上通常是 `C:\temp\`），可以直接拿来看页面长什么样。

检查脚本本身就是回归网：数据一致性、地图是否真的画出来（含光栅化后数像素）、交互状态、文案关键口径、布局是否重叠或裁切。**改文案时如果断言挂了，先判断是"文案变了断言该更新"还是"信息丢了"**——口径类关键词（起评分、数据覆盖、front_present、-128、审图号等）是故意被断言的。

### 3.3 交互与可访问性

- 唯一真源：时间只有顶栏「出海日」；范围只有一处 10/20/30；图层只有图例开关。页面内不再出现第二套控件。
- 单向数据流：`state` → `render*()`，渲染只读 state；所有变更集中在事件处理器。
- 页签 `role=tab` + ←/→ 方向键切换；Esc 取消钉住/选中；Toast 只做操作回执，不播报结论。
## 4. 数据与算法口径（改结论前必读）

### 4.1 数据源

| 用途 | 来源 | 许可 / 口径 | 覆盖 |
|---|---|---|---|
| 锋面位置 / 冷暖侧 | Zenodo `10.5281/zenodo.20356239`（全球逐日中尺度锋面数据集，上海海洋大学 Xing 等） | CC BY 4.0；0.05° 逐日；变量 `front` | 已导出 62 天：2024-07-01 ~ 2024-08-31 |
| 水温 | NOAA CoastWatch ERDDAP `noaacwBLENDEDCsstDaily`（GHRSST L4，夜间融合） | GHRSST free and open；0.05° 逐日；按 **0.5 °C 分箱**展示，不插值 | 同 62 天 |
| 底图 | Natural Earth 1:10m 陆地 / 海岸线 / 等深线 | 公有领域（可商用，无需署名） | 裁剪到 117.5–131.5°E / 25–35°N 并抽稀 |
| 历史同期统计 | 由锋面数据样本离线统计 | 2015–2024 每年 8 月 5—7 日，共 30 天样本 | 页内写明抽样口径 |

**编码含义**（数据集原始值，页面照实展示）：`-10 / 10 / 30` 锋面线（三者语义在数据说明中仍有歧义，页面统一当“锋面线”画）、`-20` 冷侧、`20` 暖侧、`-128` 缺测（**同时含陆地、湖泊、云**，无法区分“没有锋面”与“没有观测”）。

**范围与网格**：120–128°E / 27–34°N；起点 0.025（半个格），步长 0.05°，160 × 140 格；出发地默认 124.50°E, 30.20°N。

### 4.2 把握度评分（页面上唯一的"可算"数字）

```
把握度 = clamp(30 + 四项加分, 5, 95)          # 起评分 30
① 范围内锋面区数量：每个 +12，最多计 3 个
② 最近锋面距离：≤10 km +8，≤20 km +4
③ 范围内最长锋面区：≥100 km +8，≥50 km +4
④ 数据覆盖（= 100 − 缺测率）：≥85% +4，<70% −4
三档：≥70% 值得去 · 50–69% 可以看看 · <50% 线索不足
```

**不参与评分**：水温、锋面强度、海况、预报、渔场；冷暖侧只展示。这是刻意的取舍——没有真实渔获/适温数据时，把偏好算进分数会被读成预测。

### 4.3 其他口径

- **锋面区编号**：锋面线像元做连通域 → 取直径路径当中心线 → 按 6 km 抽稀 → 长度 ≥ 20 km 才编号（`F001`…）。编号是本系统内部编号，不是数据集自带的轨迹编号。
- **历史同期 `front_present`**：半径内锋面线格数 > 0 记为出现；比例 = 出现天数 ÷ 有效天数。这是历史同期页唯一口径，缺样本的年份不参与分母。
- **航时 / 油耗**：按 8 节（14.8 km/h）、1.6 L/km 估算，只用于横向比较量级。
- **投影与距离**：演示投影保证东西向与南北向等长（1 km = 1 km），所以范围环是正圆；距离 / 方位由经纬度实时计算，地图上的线与卡片数字同源。

## 5. 欠缺的功能（按"要补什么"分组）

### 5.1 数据缺口（直接影响结论可信度）

| 缺什么 | 现在页面怎么处理 | 补齐路径 |
|---|---|---|
| **锋面预报**（未来） | 「未来趋势」页只说明原因，不给任何未来数字 | 先补足逐日样本做持续性基线（今天有锋面→明天还在的概率），再接预报输入场（水温 / 流场） |
| **真实海况**（风 / 浪 / 涌） | 整卡标「示例数据 · 仅供参考」，并提示以官方海洋预报为准 | 接 ECMWF / NOAA WW3 / ERDDAP 风浪场；接入后应把出海安全提升为 L1 必答项 |
| **锋面强度** | 「未接入」 | 数据集里的 `frontal_intensity` 变量尚未下载，需补下载 + 导出编码 |
| **渔场 / 船位**（GFW 等） | 地图上是示例椭圆，标注「示例数据」 | GFW 许可为 CC BY-NC 4.0，**商用需单独授权**；先明确使用场景再谈数据 |
| **水温与锋面同源** | 页面标明两者来自不同产品 | 换 Copernicus C3S SST（0.05°，与锋面同源）需账号与下载配额 |
| **历史同期覆盖太窄** | 「当月」口径直接说明样本不足、算不出 | 按月补齐 8 月逐日样本，即可支持整月统计 |
| **历史日期不可步进** | 出海日只能选 2024-07-01 ~ 08-31 | 需要时把 2015–2024 的 8/5–7 也导出到 `data/day/`，即可在日期上直接对比 |

### 5.2 功能缺口

- 时序/动画：不能连续播放多天锋面移动；只能逐日切换。
- 输出与协作：没有导出图片 / 分享链接 / 报告；没有账号与收藏。
- 合规地图：国内正式发布必须换成带**审图号**的合规底图（当前 Natural Earth 仅用于原型演示）。GitHub Pages 因此**故意没有开启**。
- 移动端：只做了 1280 / 1680 两档布局断言，未做触屏手势与窄屏（< 900px）适配。
- 法规信息：禁渔期、航行通告、船位报告等没有接入。

### 5.3 工程缺口

- **加载体积**：62 天全量数据 3.24 MB，以 `<script>` 全量注入。日期规模再上一个量级就需要改按需加载（按日期分片 / fetch 动态导入）。
- **没有 CI**：三项检查靠手动跑；建议接 GitHub Actions，把 `node tools/*.mjs` 串成流水线。
- **没有构建/类型**：改动靠断言兜底，重构（如拆分渲染模块）前应先补断言。
- **统计与渲染耦合**：历史同期的计算逻辑写在渲染函数内，若要复用需先抽离。

### 6.3 数据更新流程（照这个顺序做）

1. `fetch_zenodo_front_samples.py <日期…>` 拉到 `Ocean/data/raw/front/`；水温用 `fetch_sst_samples.py` 拉到 `Ocean/data/raw/sst/`。
2. 跑 `export_prototype_data.py`（可加 `--dates` 只导指定日期；`--no-sst` 跳过水温）。
3. 跑三项检查；`data-check` 会验证新日期的结构与自洽，`e2e-check` 会验证页面确实用上了新数据（日期范围、对象数与文件一致）。
4. 提交 `data/**` 与（如改了）`docs/**`、`tools/**`；`data/**` 一律由脚本产出，不要在编辑器里改。

### 6.4 四条硬约束（改代码前先接受）

1. **不手改生成文件**：`data/**`、`data/base/basemap.js` 都是脚本产物；要改内容就改脚本再重跑。
2. **不编数字**：没有数据源的变量一律标「未接入」或「示例数据 · 仅供参考」，不得插值、不得用样例值冒充真实值，不得给未来天数编把握。
3. **缺数据要明说**：无观测、超范围、样本不足都必须给出原因与可行动作（换日期 / 放大范围 / 先补数据），并且不给结论。
4. **单一真源**：时间 / 范围 / 图层在界面上各只出现一处；新增功能不得再引入第二套控件。

### 6.5 已知坑（踩过一次就别再踩）

| 坑 | 现象 | 规避方式 |
|---|---|---|
| 中文路径 + netCDF-C | `netCDF4` 打不开含中文的路径（本仓库路径含「海洋锋面」） | 导出脚本内部已做临时 ASCII 路径中转；自己写脚本时同样处理 |
| CSS `display` 覆盖 `hidden` | 地图遮罩一直显示，页面上看不到数据 | 已加 `[hidden]{display:none!important}`；新增覆盖层不要再写 `display` 覆盖 |
| 只断言 `el.hidden` 的测试会漏 | 63 项全过但页面实际不可用 | e2e 用 computed style + `elementFromPoint` 命中判断 |
| PowerShell 读文件乱码 | `Get-Content` 默认按 ANSI | 用 `Get-Content -Encoding UTF8`；工具输出用 `Out-File -Encoding utf8` |
| Zenodo 下载中断 | `ProtocolError` / 半截文件 | 抓取脚本已带重试 + 重新打开归档 + `.part` 原子写入 |
| `git credential fill` 交互 | 在工具终端里会挂起 | 不要交互式调用；需要凭据时用非交互方式读取 |
| 无头 Edge 偶发不稳 | CDP 连接超时 | e2e 启动后轮询 `/json/list`，并等待页面就绪标记再断言 |

### 6.7 三分钟演示脚本（对外讲的时候照这个顺序）

1. **定位与范围**（顶栏）：出发地 124.50°E / 30.20°N，作业范围 20 km → 页面立刻给出结论：把握度 + 三档判断 + 首选锋面区（方位 / 距离 / 航时）。
2. **地图**：指出海岸线与陆地（浅色实色块）、水温色带（NOAA GHRSST）、红色锋面区中心线与编号、蓝色冷侧 / 橙色暖侧、斜线是"无观测"；滚轮放大到某个锋面区，指出比例尺跟着变。
3. **任意点查询**：鼠标停在锋面上，展示"数据类型 / 离你多远 / 是否在范围内 / 最近锋面 / 水温"，点一下钉住，Esc 取消。
4. **换日期**：点「出海日」◀▶，展示不同日期的锋面位置变化（这是真实观测回算，不是预报）。
5. **未来页**：主动说明"没有预报数据就不给未来数字"——这是产品的诚实性设计，不是功能缺失的借口。
6. **历史同期**：当日 / 近三日 / 当月，说明抽样口径与实际取样 30 天。
7. **数据说明**：数据来源（DOI / 许可）、评分规则、使用限制（含"国内发布需合规底图"）。

**常见追问与标准回答**

- 「这数据准不准？」→ 锋面是 Zenodo 上公开的 0.05° 逐日卫星锋面数据集（CC BY 4.0），水温是 NOAA GHRSST 融合产品；两者不同源，页面已标明。
- 「为什么不做未来 7 天？」→ 手上只有观测回算，没有预报输入场；编出来的天数会误导出海决策，所以只说明缺口与补齐路径。
- 「能不能直接上线？」→ 需要三件事：合规底图与审图号、真实海况数据、以及数据规模上来后的按需加载。

### 6.8 术语表

| 界面用词 | 含义 | 数据里的对应 |
|---|---|---|
| 锋面区（F001…） | 一条被编号的锋面中心线对象 | `objects[]`，长度 ≥ 20 km 才编号 |
| 短段锋面 | 太短、未单独编号的锋面线 | `front_lines` 里未进入 `objects` 的部分 |
| 锋面带 | 数据集原始锋面像元（−10 / 10 / 30） | `front_band_rle` |
| 冷侧 / 暖侧 | 锋面两侧的水团 | `-20` / `20` |
| 无观测 | 缺测（同时含陆地、湖泊、云） | `-128`，`nodata_rle` |
| 把握度 | 唯一参与评分算出的百分比 | 前端按 §4.2 公式计算 |
| 数据覆盖 | 100 − 缺测率 | `quality.nodata_percent` |
| 水温 | 海表温度（NOAA GHRSST，0.5 °C 分档） | `sst/*.js` 的游程与 `sstCell()` |
| 推荐水域 | 示例渔场占位（无真实数据） | `DEMO_SPOTS`（前端常量） |
| 历史同期 | 往年同一日期的锋面出现比例 | `clim/same-period.js`，`front_present` 口径 |
