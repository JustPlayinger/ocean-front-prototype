
# 信息架构与交互规范（v1.3）

> 日期：2026-09-12
> 适用范围：`prototype-fishing.html` / `prototype-fishing.js`
> 目的：把「渔场作业」的真实决策顺序固化为界面层级，消除冗余与主次不清
>
> **v1.1 变更**：① 时间维度收敛为顶栏「出海日」单控件（删掉"观测/预报/气候"三档，"气候"改名「往年同期」只留在该页）；② 新增**地图指针查询**（鼠标指到哪看哪的数据，可钉住）；③ 全站术语平实化（见 §7）；④ 选中态增加回执卡；⑤ 顶栏控件按使用顺序编号分组。
>
> **v1.3 变更**：① **目标鱼种下线**（顶栏由 4 组收敛为 3 组：① 从哪出发 ② 找多远 ③ 出海日；把握评分删除「鱼种偏好侧别」项，冷暖侧只展示）；② 理由：没有真实渔获/适温数据时，规则偏好会被读成预测——页面所有数字只由真实锋面数据算出。

## 1. 市场与用户需求调研（结论）

### 1.1 调研来源（可核查）

| 来源 | 关键事实 |
|---|---|
| FishTrack（消费级海钓预报 App，Surfline/Wavetrak）| 首页即"找鱼工具"：**无云 SST 图 + 叶绿素 + 真彩影像 + 流场/潮汐/月相 + 7 天海洋天气**；配套**收藏点、温跃层断点标记、航点/航线、离线图**；卖点原话 **"Save time and fuel"**（省油＝省钱，即可达性）；用户原话："SST 和海洋预报是我早上最先看的两样东西……水温断点和风/流读数决定我怎么过这一天" |
| NOAA CoastWatch 产品检索 | 锋面是**业务化产品**：`ACSPO 0.02° Super-collated SST and Thermal Fronts (L3S-LEO)`，分辨率 2 km+，时效 NRT ≤24 h；另有**叶绿素异常产品**（相对 61 天中位数），说明"锋面 + 叶绿素边缘"可直接上图 |
| NOAA TurtleWatch（太平洋岛屿）| 典型的"**锋面直接产出空间指引**"形态：用特定 SST 等温线/锋面 + 水深界线圈定可用海域（具体阈值待核实）|
| Global Fishing Watch | 定位为**捕捞活动/热点 + 管辖区图层**（事后活动分布，属"验证类"信息，非"明天去哪"的预判）|
| OpenAlex 文献检索 | ① *SST fronts affect distribution of Pacific saury*（2014，被引 56）——锋面→物种栖息分布；② *Forecasting Albacore Fishing Grounds … ML + Ensemble*（2023）；③ *Ensemble Modelling of Skipjack Tuna Habitats*（2020，被引 51）；④ *Towards a Fishing Pressure Prediction System for a Western Pacific EEZ*（2019）；⑤ *Marine heatwaves redistribute pelagic fishing fleets*（2024）——**异常年份整体改变作业分布**；⑥ *Fishing for what? understanding fisher decision-making*（2010）——渔民决策＝经济+社会+环境混合；⑦ *Smartphone application use in commercial wild catch fisheries*（2022）；⑧ 东海相关：*Swordtip Squid Habitat（ECS, 2023）*、*Largehead Hairtail Nursery Grounds（ECS, 2022）* |

> 抓取受限（未取得内容，故不作依据）：`roffs.com`、`ripcharts.com`、`bom.gov.au`、`nmefc.cn`、`oceanguide.cn`、`eastfishery.ac.cn`、Bing/DuckDuckGo。中国本土"渔情速报/渔场预报"产品细节**暂无一手证据**，下文涉及处均已标注推断。

### 1.2 用户决策链（UI 层级据此排序）

```
第 0 问  今天/这几天能不能出海？   ← 安全（风/浪/涌）+ 成本（油）+ 法规（禁渔期）
第 1 问  去哪一片？              ← 渔场线索排序（锋面/温跃层/叶绿素边缘）+ 方位 + 距离
第 2 问  怎么去、多久到？         ← 航距 → 航时/油耗
第 3 问  什么时候最合适？         ← 未来 1/3/7 天窗口 + 逐日变化
第 4 问  为什么推荐这儿、可靠吗？  ← 历史同期规律 + 算法依据 + 异常提示
第 5 问  这一片到底怎么样？       ← 地图上任意点查询（v1.1 新增，见 §3.2 / FR-13）
```

### 1.3 需求分级

- **Must**：结论先行的一句话建议；可执行点位（方位+距离）；可达性（航时/油耗）；时间窗；安全/海况；可解释依据
- **Should**：历史同期规律与异常提示；目标鱼种相关权重（v1.3 暂缓，等真实渔获/适温数据）；图层可控 + 时效标识；无数据时的诚实回退；任意点查询
- **Could（本期不做）**：AIS 活动层、三维球面、离线包、分享导出、真实大模型

### 3.4 地图指针查询（v1.1 新增交互；v1.2 改为真实数据）

| 动作 | 结果 |
|---|---|
| 鼠标移到地图任意点 | 浮层跟随指针，列出：坐标 / **这一点在数据里属于哪一类（锋面线及其原始编码 −10/10/30 / 冷侧 / 暖侧 / 无锋面）** / 离你多远+方位 / 是否在找鱼范围内 / 最近锋面的距离+方位+对象编号与长度 / 海表温度（未接入时写「待接入」）/ 当前日期与数据来源 |
| 指针落在没有观测的像元 | 只显示坐标 + 「这里没有观测数据（陆地、云或未观测，数据里统一用 -128 表示）」，不给任何数值 |
| 该日期没有数据 | 只显示坐标 + 原因，不给任何数值 |
| 点一下 | **钉住**该点（地图画十字标记，浮层固定），便于与别处对比 |
| 再点同一点 / Esc / 点 ✕ | 取消钉住 |
| 钉住期间移动鼠标 | 浮层内容保持钉住点不变（不会被指针抢走） |

实现要点：坐标反算走 `svg.getScreenCTM().inverse()`（缩放/裁切都不错位）；`mousemove` 用 `requestAnimationFrame` 节流；浮层 `pointer-events: none` 且位置钳制在地图内；**「这一点是什么」由 `OFData.cellInfo(lon, lat)` 直接查数据里的 RLE 掩码**（不再有本地近似海岸线表）；渔场区半轴用公里（绘制时乘 `KM2PX`），保证"在不在水区内"与卡片数字同源。

## 4. 交互规范（11 条）

1. **单向数据流**：`state`（唯一真源）→ `render*()`；渲染函数只读 state，不写 state。所有状态变更集中在事件处理器内。
2. **单一选中语义**：`state.select = {type, id}`；地图要素、结论卡点位、列表条目共用同一选中态（`data-type/data-id`），任何位置点击同一条目结果一致；再次点击取消。
3. **选中必有回执（v1.1）**：选中后地图上出现回执卡（名称 + 距离 + 方位 + `✕`），不再只靠"地图压暗"暗示；`✕` 与 Esc 都能取消。
4. **几何同源**：定位点到锋面/水区的距离、方位由经纬度实时计算（`nearestOnSegment` + `bearing16` + `distKm`）；地图几何与卡片数值不允许出现两套数据；地图投影保证东西/南北向 1 km 等长（否则半径圈不是正圆）。
5. **时间模型（v1.1 收敛）**：全站只有一个时间真源 `state.date`（出海日），取值 `2024-06-01 ~ 今天+6 天`，越界自动钳制并提示；数据来源由页签决定 —— **现在页=观测、未来页=预报**；"气候"不再是一个可选档，改为「往年同期」页的统计内容。
6. **范围模型**：`state.range` 唯一；半径环、范围内判定、回退规则、文案全部从它派生。
7. **反馈分工**：Toast 只用于"操作确认"（日期/图层/定位/选中）；数据结论一律落在卡片，不用 Toast 播报结论。
8. **渐进披露**：卡片默认只给结论 + 一行说明，细节收进「为什么这么判断 / 和往年比，正常吗」折叠区。
9. **空态与回退**：无数据必须说明原因（覆盖期/窗口）且不给结论，并给出可行动作（如"去看未来"）；找鱼范围内无命中时回退最近对象并**显式标注**"先给最近的"。
10. **指针即数据（v1.1 起）**：鼠标指到地图任意点给出该点**数据里的真实类别**（锋面线及其原始编码 / 冷侧 / 暖侧 / 无锋面 / 没有观测）、距离方位、最近锋面对象编号与长度，点一下可钉住，Esc 取消；落在没有观测的像元或该日期无数据时**只说事实、不给数值**。
11. **控件唯一性（v1.1）**：任一可调维度全站只出现一处（见 §3.2）；顶栏按使用顺序编号分组（① 从哪出发 ② 找多远 ③ 出海日），让"先做什么"看得见（v1.3：目标鱼种下线，顶栏由 4 组收敛为 3 组）。
