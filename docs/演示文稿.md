# 展示要点

## 地图面板

- 图层
  - 水温`SST`：颜色标识温度，越冷越蓝，越暖越黄
  - 锋面线/锋面区：锋面区直接来源于数据，锋面线平滑了曲线。_锋面强度如何表示？_
  - 冷测/暖侧：锋面线附近根据温度变化，标识冷测和暖侧
  - 无数据：陆地或未观测
  - _渔场：根据渔船数量和停留时间设计推导该位置产量，并平滑无数据部分（实际可能不平滑有突变）_
  - _考虑地图接入真实地图_

- 观测点：
  - 可选探测范围：
    - 方圆10/20/30公里
  - 两种定位方式：
    - 输入经纬度
    - 点击地图定位
  
- 日期：
  - 可逐日查看历史数据 **（没法直接看一个月的数据，因为温度可能变化较快）**
  - 有滑动条
  - 可逐日轮播，查看演变进程

## 统计面板

- 结论：（并非局限于预测结果，描述附近是否存在锋面区？）
  - 直接给出选定作业范围内是否存在锋面区
  - 包含置信度、附近锋面区方位，大概需要的时间、油耗（或许可删除，这里不是预测而是统计）
  - 评分依据：
    - 同样可删除

- 四个面板：
  - 当前：
    - **需要考虑的是当前的数据往往是没有的，这其实也是一种预测**
    - 应该包含：
      - 作业范围内锋面区数量
      - 最近的锋面区的距离
      - 选定位置所在的锋面位置
      - 置信度，可删除
  
  - 历史：
    - 可按不同周期长度查看选定范围内统计数据：
      - **存在的问题是锋面线往往分布分散，较小的范围内统计的锋面数量往往是零，所以这里的统计范围应当比活动范围更大，大小仍需考虑**
  
  - 预测：
    - 类似当前面板，但这里统计的不再是锋面区而是渔场分布
    - **考虑到打算用一个图层来描述鱼产量，这里或许可以直接展示预测范围内的预测鱼产量地图**
    - 包含置信度和预测依据（基于模型可解释性）
    - 也可以选择周期由算法遍历选择最佳日期（根据鱼产量和置信度）
